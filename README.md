# 🏙️ ITBI Fortaleza — Real Estate Data Analysis

## 📌 Overview

This project presents a data analysis of **real estate transactions in Fortaleza, Ceará, Brazil**, based on records from the **Imposto sobre a Transmissão de Bens Imóveis (ITBI)**.

The project was developed as part of the **Business Intelligence** course in the **Actuarial Science undergraduate program at the Federal University of Ceará (UFC)**.

The analysis explores the process of data preparation, cleaning, transformation, feature engineering and visualization using Python, with the goal of extracting relevant information about the real estate market in Fortaleza.

---

## 🎯 Objectives

The main objectives of this project are:

- Import and explore the original ITBI dataset;
- Understand and classify the available variables;
- Convert variables to appropriate data types;
- Select relevant attributes for the analysis;
- Identify and treat missing values;
- Create new variables through feature engineering;
- Verify temporal consistency of the records;
- Explore the distribution of real estate transactions;
- Analyze temporal and geographic patterns;
- Support the development of an interactive Business Intelligence dashboard.

---

## 🗃️ Dataset

The dataset contains information about **ITBI real estate transactions in Fortaleza**.

Among the available information are:

- Property identification;
- Transaction and registration dates;
- Construction information;
- Neighborhood;
- Property characteristics;
- Monetary values;
- Geographic coordinates;
- Other cadastral information related to real estate transactions.

The data used in this project come from the **Open Data Portal of the Municipality of Fortaleza / SEFIN**.

---

## 🧹 Data Cleaning and Preprocessing

The data preparation process includes:

- Inspection of the original dataset;
- Data type conversion;
- Treatment of date variables;
- Conversion of numerical variables;
- Analysis of missing values;
- Removal of variables not required for the analysis;
- Verification of duplicate records;
- Temporal consistency checks;
- Preparation of the dataset for exploratory analysis and visualization.

---

## ⚙️ Feature Engineering

New variables were created to improve the analytical potential of the dataset, including information derived from:

- Registration dates;
- Construction dates;
- Property age;
- Construction decade;
- Temporal classifications;
- Consistency between construction and registration periods.

These transformations allow the data to be analyzed from different temporal and real estate perspectives.

---

## 📊 Exploratory Data Analysis

The project explores different dimensions of the ITBI data, including:

- Evolution of real estate transactions over time;
- Distribution of transactions by neighborhood;
- Characteristics of the properties;
- Construction periods;
- Property age;
- Monetary variables;
- Geographic distribution of transactions.

The analysis combines descriptive statistics and data visualization to identify patterns in the real estate market of Fortaleza.
